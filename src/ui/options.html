How it decides

  • Default. A new tab or window that a page opens to another site is closed. Windows to the same site stay open, and so do links you click yourself, including target="_blank" links and forms.
  • Block all popups. Also closes same-site windows and plain clicks on new-tab links. Ctrl/⌘-click, Shift-click, middle-click and the “Open link in new tab” menu still open links.
  • Allow popups. Nothing is blocked on that site. Use this for sign-in, payment or chat windows that a site needs.
  • Blank windows are judged by their first destination, and same-site windows that redirect to another site within 10 seconds are closed.

Limits

  • A blocked window exists for a moment before it is closed; the other site may already have received the request.
  • Popup Guard does not remove in-page overlays, modal dialogs, notifications, or redirects of the current tab (“tab-unders”).
  • It cannot act on browser pages (chrome://, the Web Store) or on popups that the browser's own blocker already stopped.
  • Cross-site sign-in popups (for example “Sign in with Google”) are blocked by default; choose Allow popups for that site.
